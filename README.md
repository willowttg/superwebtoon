# 큰 힘에는 큰 책임이 따릅니다 (가제)

사람들이 스스로 단점이라 여기는 특성의 밝은 면을 **"초능력"**으로 재해석하는 일상 힐링 인스타툰.

> 예시 에피소드: 「타인의 감정을 꿰뚫는 초능력자들」 — 눈치를 많이 보는 사람들의 이야기

📱 **작업 프리뷰**: https://willowttg.github.io/superwebtoon/

## 콘셉트

- **장르**: 일상 힐링 / 공감툰
- **핵심 메시지**: 당신의 단점은 사실 초능력이다
- **분량**: 표지 제외 6컷 내외
- **목표 독자 행동**: 공감 → 위안 → 비슷한 성격의 친구를 댓글로 태그 (바이럴)

## 로드맵

1. ✅ 유사 장르 성공사례 분석 → [docs/research/01-genre-analysis.md](docs/research/01-genre-analysis.md)
2. ⬜ 생성 자동화 파이프라인 스킬 (소재 발굴 → 대본 → 콘티 → 이미지 생성)
3. ⬜ 인스타 업로드 및 관리 스킬 (게시, 해시태그, 댓글/인사이트 관리)
