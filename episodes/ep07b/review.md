# EP 리뷰

## 반드시 고칠 것

- **컷1·3~5** — `두부는 '싫어'를 말하려 하면 "시…"까지만 나오고 뒤가 다른 말로 샌다.`는 규칙에서 나쁜 예로 직접 든 `"'싫어'는 '시'까지만 나온다"`와 사실상 같다. 실제 거절 못 하는 경험보다 발음 말장난이 앞서고, 컷5의 `싫어!`로 설정까지 무너진다. 수정안: 제목을 「부탁이 끝나기도 전에 '응'부터 나오는 초능력」으로 바꾸고, 컷1은 `탱자: 내일 이사 좀— / 두부: 응! / 탱자: 아직 날짜도 안 말했는데?`로 시작한다. 컷3~5도 `시…` 말장난 대신 부탁을 듣자마자 수락하는 행동으로 통일한다. → 기각: 제목은 사용자 확정, '시…' 말장난은 대사·장면에서 허용(내레이션만 금지). 단 반복은 4·6컷에서 줄임.

- **컷1~6** — `내레이션 없음(전 컷 "?")`은 “내레이션·속마음은 1인칭”과 “내레이션은 컷당 2줄 고정”을 정면으로 어긴다. 대사만으로 설명까지 떠맡아 컷1과 컷4의 글자 수도 과하다. 수정안: 내레이션을 각각 다음처럼 넣는다.  
  컷1 `나에겐 부탁이 끝나기도 전에 / '응'부터 나오는 초능력이 있다.`  
  컷2 `나는 망설이다 꺼낸 부탁을 / 웬만하면 그냥 지나치지 못한다.`  
  컷3 `토요일엔 꼼짝도 안 하려 했는데 / 정신 차려 보니 장갑을 받고 있다.`  
  컷4 `거울 앞에선 거절도 잘했는데 / 동생 목소리에 지갑부터 열었다.`  
  컷5 `김장, 콘서트, 동생 심부름. / 토요일엔 내가 셋은 있어야 한다.`  
  컷6 `친구가 응원봉을 흔드는 동안 / 나도 모르게 다음 곡을 따라 불렀다.` → 기각: B안은 사용자 요청으로 만든 '내레이션 없는 대사 전용' 비교 실험.

- **컷4** — `시. 러. 시러. 시렁. 실…`과 `시… 신사임당.`은 같은 발음 개그의 반복이고, 거울 연습·제시카 밈·만원 부탁·오만원 착각까지 한 컷에 펀치가 경쟁한다. “그 순간 눈에 보이는 것·입에서 나오는 말로 쓴다”는 규칙에도 실제 경험 쪽이 약하다. 수정안: 포스트잇을 `안 돼 / 이번 주는 어려워 / 다음에`로 바꾸고 발음 대사는 삭제한다. `콩: 누나, 만 원만. / 두부: 응, 여기. / 콩: 오만 원인데? / 두부: …잔돈 없어.`만 남겨 실제 거절 실패로 웃긴다. → 반영

- **컷5** — 컷4에서는 맨손으로 음절을 세고 돈을 건넸는데 곧바로 `두 손엔 빨간 고무장갑 그대로`라 시간 흐름이 성립하지 않는다. 또한 단점 구간의 마지막 자폭은 좋지만, 현재는 제목의 절대 규칙을 깨야만 웃을 수 있다. 근거 규칙은 “장면만으로 상황이 성립하는가”와 “단점 구간의 마지막 컷도 … 한 번 더 자폭으로 끝낸다”이다. 수정안: `토요일 오후, 김장 뒤` 라벨을 넣고 장갑은 손이 아니라 바닥에 벗어 둔다. 대사는 `밤톨: 남은 건 내가 다 취소해 줄게. 넌 쉬어. / 두부: 싫어, 내가 할게. / 밤톨: 남의 부탁엔 응, 내 도움엔 싫어?`로 바꾼다. → 부분 반영: 라벨·장갑 바닥 반영, 대사는 기존("…그건 발음이 되네.") 유지 — 제안 대사가 설명조.

- **컷6** — 소라의 `같이 가자고 했을 때 사실 싫었지. 나 알아.`는 조용하고 소심한 소라가 상대 마음을 단정하는 말투라 성격과 어긋난다. 마지막도 `시… 시작은 좀`이라는 말장난을 또 반복해 저장할 위로보다 설정 설명이 남는다. 근거 규칙은 “그 캐릭터가 그 순간 실제로 내뱉을 법한 길이·어투인가”와 “마무리 = 저장 유도 문장 + 태그 CTA”이다. 수정안: `소라: 오늘 무리한 건 아니지? / 두부: 처음엔 좀. 그래도 너랑 오길 잘했어.`로 바꾸고 CTA를 잇는다. → 반영

## 고치면 좋은 것

- **컷2** — `그날 눕는 날인데.`는 의미는 통하지만 실제 속말치고 어색하고, 장점 컷의 웃음도 약하다. 근거 규칙은 “소리 내 읽었을 때 사람이 쓰는 말인가”이다. 수정안: `그날은 침대랑 선약 있는데.`로 바꿔 두부다운 생활 개그를 살린다. → 반영

- **컷3** — 공유 컷의 압박은 선명하지만, 미숙이 현재는 일방적으로 일을 떠넘기는 사람처럼만 보인다. 캐스트의 “잔소리 = 걱정”이 드러나지 않는다. 수정안: 첫 대사를 `너 김치 떨어졌지? 토요일에 이모네 김장 가자. 싫으면 말고~`로 바꿔 걱정에서 시작된 참견임을 한마디로 보강한다. → 반영

- **컷1·6** — 기존 EP.07과 제목·손마이크의 종류와 색·캡션 구조까지 완전히 겹친다. 별도 편이라면 “새 편은 이 표와 겹치지 않는 종류·색으로 정한다”는 소품 규칙 위반이다. 수정안: 대체안이라면 상단에 `기존 EP.07 대체 콘티`라고 명시해 둘 중 하나만 제작하고, 별도 편이라면 새 제목과 주황색 응답 버튼 같은 다른 소품으로 분리한다. → 반영: 상단에 A안 비교용 대체 콘티임을 명시.

## 잘된 점

- 컷3의 `싫으면 말고~`와 이미 사 둔 고무장갑, 엄마 반대쪽을 향한 발끝은 말·소품·몸짓이 동시에 압박을 보여 주는 강한 공유 컷이다.
- 소라의 조심스러운 부탁, 콩의 무신경한 현금 요구, 밤톨의 해결 제안은 조연 역할과 대체로 잘 맞는다.
- 장점→단점 첫 등장→심화→따뜻한 마무리의 배치와 구도·감정 기호 분산은 명확하다.

## 한 줄 총평

지금은 발음 말장난과 컷5의 설정 붕괴 때문에 저장·태그하지 않겠지만, 이를 “부탁이 끝나기 전에 응부터 하는 사람”의 실제 경험으로 바꾸면 컷3과 컷5는 바로 친구에게 보낼 만하다.
