## 관찰

- **표지 = 텍스트가 주인공.** 성공 표지는 캐릭터보다 카피가 크다. 굵은 산세리프 또는 손글씨, 핵심 단어만 포인트 컬러(뱁새 핑크, 솜비 주황, 하루살이 파랑). 우리 "○○하는 사람은 사실 초능력자입니다" 공식과 맞는다.
- **정체성 호명형이 참여율을 만든다.** 솜비·하루살이·이연필처럼 "이런 사람 특징"으로 시작하면 좋아요 대비 공유·댓글이 높다. 사연툰(키크니·그리고)은 좋아요는 크지만 우리가 따라갈 구조가 아니다.
- **흰 배경 + 최소 선이 다수.** 서늘한여름밤·키크니·펀자이씨·솜비 모두 배경 없음. 저채도 일상 / 포인트 컬러 발동 컷 전략은 이 위에서 충분히 차별화된다.
- **슬라이드는 8장이 상한처럼 쓰인다.** 조사 게시물 대부분이 6~8장. 표지 + 6컷 + (CTA) 구성이 표준 범위 안.
- **캡션은 짧고 해시태그는 시리즈 고정.** 펀자이씨 `#순간을달리는할머니`, 하루살이 `#하루살이일상툰`, MBTI툰 `#m툰_유형별시리즈`.
